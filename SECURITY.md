## Reporting a Vulnerability
Please **do not** open public GitHub issues for security vulnerabilities.

1. Send an email directly to [agusdwirianto@gmail.com](mailto:agusdwirianto@gmail.com) with the subject `[SECURITY REPORT] AUDIRA Desain UI/UX`.
2. Detail the vulnerability, affected components/scripts, impact severity, and proof-of-concept steps.
3. Our team will acknowledge receipt within 48–72 hours and provide a remediation plan.

## Scope
In-scope components include:
- CLI installation and automation scripts
- Data parsers, search engines, and Python execution environments
- Workspace configuration files and dependencies
